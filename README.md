An automated, cross-language bioinformatics pipeline combining **Python** (data wrangling and statistical testing) and **R** (multimodal biological visualization). The pipeline ingests high-dimensional RNA-Seq expression data, performs mathematical normalization and hypothesis testing, and generates a standalone, interactive HTML dashboard.

🔗 **[View the Live Interactive Dashboard Here](https://Ayan-Goswami.github.io/bioinfo-volcano-report/)**

## Project Overview

Understanding the molecular mechanisms underlying biological responses requires robust transcriptomic profiling. This project serves as a complete computational workflow designed to identify differentially expressed genes (DEGs) between two distinct biological states (e.g., Control vs. Treated). 

By pairing Python’s efficient, vectorized array computing with R’s superior publication-ready visualization ecosystem, this project demonstrates a modern, polyglot approach to data science. The entire workflow is orchestrated using **Quarto**, with memory shared directly between languages via the `reticulate` bridge, eliminating the need for intermediate disk read/writes.

## Architecture & Workflow

```text
cleaned_expression.csv (11,900+ Genes × Replicates)
       │
       ▼ [Python Engine: Pandas / NumPy / SciPy]
  • Matrix Transposition & Zero-Variance Filtering
  • Log2 Transformation: log2(counts + 1)
  • Welch's t-test (Row-wise, two-tailed)
       │
       ▼ [In-Memory Transfer via Reticulate]
  • Shared DataFrame (`py$expression_matrix`)
       │
       ▼ [R Visualization Suite: ggplot2 / Plotly / pheatmap / DT]
  • Threshold Filtering (|Log2FC| ≥ 1.0, p < 0.05)
  • Interactive Volcano Plot with Hover Tooltips
  • Top-30 Differentially Expressed Genes Heatmap
  • Searchable & Paginated Data Table
       │
       ▼ [Quarto HTML Engine]
Standalone, Interactive Web Report (No active server required)

```

## Methodology & Statistical Approach

1. **Preprocessing:** Raw sequence counts are subjected to a zero-variance filter to remove uninformative features. The data is then normalized using a `log2(x + 1)` transformation to stabilize variance across the vast dynamic range of transcriptomic data.
2. **Effect Size:** Differential expression is quantified by calculating the Log2 Fold Change (Log2FC) between the experimental and control group means.
3. **Significance Testing:** To evaluate statistical significance while accounting for potential heteroscedasticity between biological groups, **Welch’s unequal variances t-test** is applied row-wise using `scipy.stats`.
4. **Outlier Scaling:** Extreme $p$-values ($p = 0.0$) generated by mathematically identical replicates are capped at $1 \times 10^{-20}$ to prevent infinite coordinate distortion on the volcano plot.

## Dashboard Features

* **Interactive Volcano Plot:** Simultaneously maps biological magnitude (Log2FC) against statistical significance (-Log10 p-value). Integrated with Plotly, users can hover over individual points to reveal specific gene symbols, exact fold changes, and $p$-values.
* **Hierarchical Clustering Heatmap:** Unsupervised sample-level visualization isolating the top 30 most significant DEGs. Row Z-score scaling is applied to confirm that the identified genomic signatures cleanly segregate the experimental samples from the controls.
* **Searchable Biomarker Directory:** A dynamic, paginated query table built with `DT`, allowing researchers to search, filter, and export the precise normalized metrics for all statistically significant genes.

## Installation & Local Execution

### 1. Clone the Repository

```bash
git clone [https://github.com/Ayan-Goswami/bioinfo-volcano-report.git](https://github.com/Ayan-Goswami/bioinfo-volcano-report.git)
cd bioinfo-volcano-report

```

### 2. Install Dependencies

**Python Requirements:**

```bash
pip install pandas numpy scipy

```

**R Requirements:**
Run the included setup script to install all necessary R packages:

```bash
Rscript setup.R

```

### 3. Render the Dashboard

Execute via the Quarto CLI or click **Render** in RStudio:

```bash
quarto render index.qmd

```

Open `docs/index.html` (or `index.html` depending on your output directory configuration) in any web browser to explore the dashboard locally.
